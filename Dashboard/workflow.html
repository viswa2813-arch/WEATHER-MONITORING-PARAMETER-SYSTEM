TECHNICAL OPERATION

Four stages of the system

01 / SENSE

Environmental Sensing

The BME280 measures temperature, humidity and atmospheric pressure. The rain sensor provides an analog rain/wetness reading.

02 / PROCESS

Local Processing

The Raspberry Pi Pico W reads the sensor signals and converts the measurements into usable values.

03 / COMMUNICATE

Wireless Telemetry

The Pico W connects to Wi-Fi and sends the sensor measurements to the Express.js server using HTTP POST.

04 / VISUALISE

Real-Time Dashboard

JavaScript retrieves the latest values from the API and displays them through the monitoring interface.
