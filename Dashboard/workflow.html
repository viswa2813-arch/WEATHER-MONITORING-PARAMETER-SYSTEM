SYSTEM ARCHITECTURE

How your data
travels.

The Weather Parameter Monitoring System follows a simple IoT pipeline. Sensors collect environmental data, the Raspberry Pi Pico W processes it, and the web dashboard displays the latest readings.

DATA FLOW SENSOR → DASHBOARD Real-time IoT telemetry
01 SENSE Sensors
02 PROCESS Pico W
03 TRANSMIT Wi-Fi
04 SERVE Express.js
05 DISPLAY Dashboard

Wi-Fi Transmission

TRANSMIT

The Pico W connects to Wi-Fi and sends the processed weather data to the backend using an HTTP POST request.

DATA PACKET
{ "temperature": 32.9, "humidity": 36.1, "pressure": 1010.6, "rainLevel": 75.0 }
PROTOCOL Wi-Fi → HTTP POST → /api/weather

BACKEND

Express.js Server

RECEIVE

The Node.js and Express.js backend receives the incoming sensor data and keeps the latest weather values available through REST APIs.

POST /api/weather Receive sensor data
GET /api/weather Return latest data
GET /api/status System status
SERVER Node.js + Express.js
